## 4. 1.4.1 60분 소크 (15 Mbps)

**1차 (02:44\~ KST): 3분 만에 중단.** 시작 165\~172초에 s 가 순간 정지 — 호스트 샘플 간격이 1.1초 → 2.4\~2.7초로 늘고 s 전체 CPU 95\~96%(두 코어 100%),
하향 처리량 6 → 0 → 1 Mbps 뒤 몰아치기(172초 4,435 수신·3,875 유실), 서버 `dropped 361 stale pending packet(s)`. 가드가 s 3연속 초과로 트립(02:47:52).
상향은 0 유실. 서명은 multi-fec-00 이 본 "기제 2"(호스트 순간 정지 → 전 경로 무수신 → 송신 정지 후 일괄 방출)와 같다 — 1.4.1 의 새 결함이 아니라 미해결 항목.

**2차 (04:20\~05:21 KST): 60분 완주.** 상향 0.161% · 하향 0.352%(9,757 / 20,560 패킷), client EAGAIN 403, 가드 트립 0.

| 자원 (30초 간격) | 시작 → 30분 → 60분 | FD | 재시작 |
|---|---|---|---|
| client | 13.4 → 16.6 → 16.6 MB | 8 → 8 | 없음 |
| server | 22.8 → 30.0 → 30.0 MB | 9 → 8 | 없음 |
| relay r / rs2 | 2.6 / 1.9 MB 고정 | 8 → 7 | 없음 |

- **누수 없음** — RSS 는 초반 램프 뒤 30분부터 평탄, FD·스레드 고정, 프로세스 재시작 0.
- **손실은 전부 호스트 순간 정지와 겹친다.** 손실 구간(상향 18 · 하향 11) 시각이 호스트 샘플러가 2\~6초 밀린 시각과 일치:
  c 정지 789·1838·2339·2463·2587·3327·3516·3579초 ↔ 손실 790·1839·2340·2464·2587·3330·3517·3580초,

- steal 은 0 에 가깝게 보고되지만 샘플러 자신이 2\~6초 멈춘다 — VM 이 스케줄되지 못한 순간으로 본다(Proxmox 호스트 쪽 원인은 미확인).
  1차가 3분 만에 끊긴 것도 같은 현상(s 정지). 1.4.1 고유 문제가 아니라 미해결 "기제 2"(호스트 순간 정지 → 전 경로 무수신 → 일괄 유실)이다.

- **1.4.0 ↔ 1.4.1 혼용: 전 조합 정상** — 홉 단위로 차례로 올려도 된다.
