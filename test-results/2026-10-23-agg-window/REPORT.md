## 판단

- **35~40 Mbps 에서 aggregate 손실이 사라졌다**(0.9 → 0.02 %, 2.1 → 0.07 %) — 송신 창 고갈이 원인이었다는 해석과 맞는다.
  이제 aggregate 도 duplicate 와 같은 **각 방향 40 Mbps** 까지 손실 0.1 % 이하(같은 날 duplicate 40 Mbps 0.19 / 0.37 %).
- **50 Mbps 이상은 두 모드 모두 무너진다**(duplicate 50: 2.7 / 8.6 %). v4 에서도 EAGAIN 이 남고 분배가 rs2 쪽으로 쏠린다
  (50 Mbps 송신 455k : 681k). CPU·링크는 여유 — 원인 미분리(경로별 rate 추정에 따른 배분 쏠림, 순간 버스트, VM 쪽 후보).
- 회선 합산 이점은 이 망(경로 대역폭 제한 없음)에서는 여전히 볼 수 없다 — 경로별 속도 제한 시험이 필요하다.
- 1회 측정. 확정하려면 v3/v4 를 번갈아 2~3회.
