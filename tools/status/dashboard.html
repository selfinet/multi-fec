구성도 — 지사 ⇄ relay ⇄ server

relay 세션 표로 그린다(선 1개 = 세션 1개). 선 위 NIC 는 커널이 실제로 고르는 송신 NIC(ip route get)이고, relay 칸의 "수신" 은 리슨 IP 가 붙은 NIC 다 — 둘이 다르면 주황으로 표시한다(소스 IP 는 송신 NIC 를 정하지 않는다). 빨간 점선 = 늘 보이던 지사가 그 relay 에 세션이 없음. 선 아래 ↑↓ 는 그 세션의 구간 트래픽(nft 카운터, ↑ = server 쪽으로) — 선 굵기도 비례. client 쪽은 들어오는데 server 쪽 응답이 0 이면 빨간 선 · "응답 없음"(60초 넘게 이어지면 경보). 세션 목록의 숫자를 누르면 추이.

relay 기준 — 지사 × relay

relay 로그·소켓만으로 만든 표다. 지사 = 키 지문(서비스망은 PSK 가 지사). 칸 = 그 relay 를 지나는 세션(지사 주소·지속 시간). relay 는 60초 무통신 세션을 지우므로 "없음" 은 최소 1분 이상 끊겼다는 뜻이다. 세션별 트래픽 양은 OS 가 주지 않아 표시하지 않는다.

relay 세션 구간 트래픽 Mbps / pps (nft 카운터)

owd 는 편도 지연이며 양쪽 시계에 의존한다. 1.3.2 이하 클라이언트는 owd 대신 옛 rtt 표기라 비워 둔다.
